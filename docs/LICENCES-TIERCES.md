# Éléments tiers embarqués dans l'appli

## Police Inter

- Fichier : `app/src/main/res/font/inter_variable.ttf` (Inter variable, graisses 100 à 900,
  alphabet latin), converti depuis le fichier woff2 livré avec Lumière sur le web.
- Copyright 2016 The Inter Project Authors (https://github.com/rsms/inter).
- Licence : SIL Open Font License 1.1 (https://openfontlicense.org). La police peut être
  embarquée et redistribuée avec l'appli ; elle ne peut pas être vendue seule.

## Icônes Lucide

- Tracés repris dans `app/src/main/java/fr/lumiere/tv/ui/theme/LumiereIcons.kt`, tels que Lumière
  les utilise sur le web (lucide-react).
- Copyright Lucide Contributors (https://lucide.dev) ; une partie des icônes vient de Feather,
  copyright Cole Bemis (licence MIT).
- Licence : ISC.
